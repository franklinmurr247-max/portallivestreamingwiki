A
API — Interfaz de Programación

Una API (Application Programming Interface) es un conjunto de reglas y protocolos que permite a diferentes aplicaciones comunicarse entre sí. Posibilita que tu portal consuma datos externos como listas de reproducción de radio, vídeos de YouTube o información de redes sociales.

→ Streaming → CMS Tecnología
B
Blog — Bitácora digital

Un blog es una publicación web con entradas ordenadas cronológicamente. Puede integrarse en tu portal como sección de noticias, programación de radio o actualizaciones de tu canal de TV.

→ CMS → Wiki Contenido
C
CMS — Sistema de Gestión de Contenido

Un CMS (Content Management System) como WordPress, Joomla o Ghost te permite crear, editar y publicar contenido sin necesidad de programar. Es el motor detrás de tu wiki, radio y canal de TV.

→ Wiki → Hosting Gestión
D
Dominio — Dirección web

Un dominio es la dirección única de tu portal en internet (ej: miportal.com). Se compra a registradores como Namecheap o se obtiene gratis en plataformas como Freenom con extensiones .tk o .ml.

→ Hosting Infraestructura
H
Hosting — Alojamiento web

El hosting es el servicio que almacena los archivos de tu portal y los sirve a los visitantes. Opciones gratuitas: GitHub Pages (estático), InfinityFree (PHP+MySQL), Netlify. Para tu portal multimedia se recomienda InfinityFree o 000WebHost.

→ Dominio → CMS Infraestructura
P
Podcast — Audio bajo demanda

Un podcast es un programa de audio disponible bajo demanda, descargable y suscribible mediante RSS. Se diferencia del streaming de radio en que el oyente elige cuándo escuchar. Puede integrarse en tu radio online mediante plataformas como Spreaker o Anchor.

→ Streaming Audio
S
Streaming — Transmisión en tiempo real

El streaming es la transmisión continua de audio o vídeo en tiempo real a través de internet sin necesidad de descargar el archivo completo. Tu radio usa streaming de audio (Icecast/AzuraCast) y tu TV usa streaming de vídeo (YouTube Live / Twitch).

→ API Tecnología Multimedia
W
Wiki — Enciclopedia colaborativa

Una wiki es una colección de páginas web interconectadas que pueden ser editadas por los usuarios. El nombre proviene del hawaiano "wiki wiki" (rápido). La más famosa es Wikipedia. En tu portal, la wiki funciona como diccionario temático con términos enlazados entre sí.

→ CMS → Blog Colaboración
